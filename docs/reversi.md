# 黑白棋

在大厅进入「棋类」第二页，选择黑白棋。可用一台平板双人同屏、两台手机联机，或在手机和平板与五档电脑对弈。手机联机双方准备后由房主开局。同屏房间可直接开局。手机人机默认为你执黑，平板人机可选执黑或执白。

## 落子和翻面

棋盘为 8×8 格，中央四枚棋子交叉摆放，黑方先行。小圆点标出当前一方的合法落点。点格预选，再点「确认落子」。新棋子和已有同色棋子必须在同一直线上夹住连续的对方棋子。横、竖、斜线同时成立时，被夹住的棋子全部翻面。

翻面从靠近落点的棋子开始，最长 0.9 秒。开启减少动态效果时直接显示新局面，并高亮翻过的格子。最新落点用棋子中央的金色点标记。

一方无处可下且对方仍有合法落点时，系统自动停一手，棋谱显示「黑方无处可下，停一手」或对应的白方提示。双方都无合法落点或棋盘下满时结束，按盘上黑白子的数量判胜，相同为和。也可认输，终局公开棋谱和盘面子数记入本浏览器战绩。

准备页可设置棋钟。无合法落点触发自动停一手时，棋钟直接交给实际能落子的一方，被跳过的一方不耗时也不加秒。详见 [棋类棋钟](board-clock.md)。

## 悔棋和人机

真人对局每方每局最多悔棋三次。手机联机由对方同意，同屏需确认，次数扣在最后实际落子的一方。悔棋回到发起方上一次实际落子之前，恢复翻过的棋子，并移除这手及随后的棋谱记录，包括自动停一手。本局尚未落子的一方不能发起悔棋。详见 [棋类悔棋](board-undo.md)。

电脑思考时落子和悔棋按钮不可用。人机悔棋次数不限，改走后电脑按恢复后的局面应手。引擎在独立 worker 中搜索，普通及以上在中前盘优先占角，余 12 格以内完整计算终局子差。入门和简单档在残局也从候选着法中随机选点。详见 [棋类 AI](board-ai.md)。

## 动画教程与验证

八段教程包括中央四子、合法落点、连续翻面、多方向翻面、自动停一手、抢角、终局数子和和棋。每段用正式引擎生成快照，和正式房间的对局进度分开保存。

运行 npm test 验证开局落点、八方向夹翻、自动停一手与悔棋、数子和棋、人机残局穷举对照及房间流程。运行 npm run build 检查协议和界面类型。

# 棋类悔棋

中国象棋、国际象棋、围棋和五子棋在对弈中支持悔棋。

- **手机联机**　点「请求悔棋」，对方可以同意或拒绝。答复前可以撤回。对方同意后，退回到请求者最近一手之前。若对方已经应手，两手一起撤销。有人走出新的一手时，原请求作废。
- **双人同屏**　点「悔棋」并确认，撤销棋谱最后一手，次数计入走出该手的一方。
- **人机对弈**　电脑走完后点「悔棋」，直接退回到你上一手之前。悔棋次数不限。重新行棋后，电脑从新的棋谱计算应手。

真人对局每方每局最多成功悔棋 3 次。拒绝和撤回不扣次数。等待开局、对局已结束、围棋确认死子或有和棋请求待处理时，悔棋不可用。围棋的「停一手」沿用棋谱中的着法记录，也可以撤销。

悔棋会缩短棋谱。棋盘直接显示恢复后的局面，末手标记和轨迹跟随新的最后一手。棋谱为空时清除标记和轨迹。

## 服务端与验证

`chessUndo`、`xiangqiUndo`、`stoneUndo` 使用 `{ action }`。联机的 `request`、`accept`、`decline` 和 `cancel` 按房间认证座位执行。房间仅为双人同屏和人机把 `request` 改写成内部 `direct`，并单独传入受信任的次数选项。房间拒绝客户端发送的 `direct`。成功回退后作废旧的自动行棋任务，广播前按恢复后的局面重新检查电脑轮次。

国际象棋由 `chess.js.undo()` 恢复规则状态，并从撤销记录恢复棋子身份。中国象棋用与电脑搜索共用的逆推函数恢复棋盘，截断重复局面记录。围棋弹出每手快照，恢复提子数并删除被撤销的盘面键。五子棋清除被撤销的落点与获胜连线。

`npm test` 中的 `tests/boardUndo.test.ts` 覆盖四款棋类的一手、两手回退、协商权限、次数、国际象棋特殊着法、围棋提子与同形再现、中国象棋重复局面，以及电脑搜索取消与重算。用 `npm run build` 验证协议、视图与客户端类型。

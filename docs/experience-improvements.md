# 2026-10-20 大厅与聚会体验改进

## 已实现

1. 手机横屏使用完整的 1040px 横向画布，按宽高等比缩放、居中，并裁掉缩放前的布局空白；竖屏继续正常滚动。软键盘出现时不重新压缩画布。
2. 继续游戏上移；竖屏加入入口收起，邀请链接保留直接入座入口；横屏两款游戏与入桌表单同时出现。
3. 全局共享屏幕常亮状态，处理后台释放、返回前台重试、系统拒绝、延迟授权与页面销毁；不支持或 HTTP 环境显示真实原因。
4. 两款游戏和两种设备模式均提供工具入口：常亮、当前阶段规则、聚会战绩。横屏遮罩增加返回大厅。
5. 准备页明确缺人、离线和未准备状态；房主可补齐易档机器人，或继续逐座选档。
6. 两款游戏提供一键练习：创建手机房、等待服务端房主状态、补机器人、准备、开始。失败保留房间与凭证，避免 ACK 先于状态导致的抢跑。
7. 斗地主纯牌型和比较规则移入共享模块，前端按钮与上滑使用同一校验；服务端保留最终判定，洗牌随机源仍仅在服务端。
8. 前后台恢复时重新认证并拉取状态；前台应用心跳与服务端原生 ping/pong 检测失联。连接中断时可手动重连，不自动重放出牌。
9. 结算解释得分或升级，提供公开有效出牌逐手回顾、PNG 战绩图片；本浏览器保存最近 100 副公开结算。保存记录不包含 token 或未出手牌。
10. 新增独立大厅样式与工具样式模块，修正浅底座位文字和结算面板的对比度、短横屏滚动裁剪。初始化本地 Git；尚未创建提交或配置远端。

## 仍需实际设备验证的边界

- iOS Safari、Android Chrome 的横竖屏、软键盘、刘海安全区域和实际手指操作；桌面视口模拟不能替代真机。
- 常亮在普通局域网 HTTP 上受浏览器安全上下文限制。此改动没有配置 HTTPS、安装证书或修改系统信任设置。
- 锁屏、系统杀后台、切 Wi-Fi 时的实际恢复时延与系统省电策略；单位测试验证的是应用生命周期与协议逻辑。
- 战绩为当前浏览器的公开结果记录，并非运行中牌局存档；服务重启仍会清空内存中的房间。

## 网站品牌标志：围桌

- 采用四个座位围绕中央桌面的四向对称造型，中央菱形代表一起开局的棋子；适用于牌类、棋类及后续其他桌游，人数不受四个座位的装饰图形限制。
- 墨绿 `#244B3C`、米白 `#FAF8EF`、暖金 `#D6BE87`，沿用网站配色。64×64 矢量画布，无字体和外部依赖。
- 资产：`public/brand/icon.svg`、32px 页签 PNG、180px Apple 主屏幕图标、512px PNG。PNG 从高分辨率矢量渲染后缩小；检查 16–128px 可读性。
- 网站页签、主屏幕图标引用及主题色已接入 `index.html`；大厅、平板与握牌页通过 `BrandMark.vue` 共用图标。生产构建与资源 HTTP 冒烟通过。

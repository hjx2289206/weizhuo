# 国际象棋

国际象棋参照中国象棋接入共用房间、邀请、断线恢复、教程与战绩。提供真人手机联机、平板双人同屏和五档人机对弈。棋盘、六种棋子和首页封面均为本项目原创 SVG；没有使用字体棋子或外部棋盘图片。

## 使用

- 大厅横屏，在「棋类」选择国际象棋。
- **平板双人同屏**：点同名按钮后竖放平板，两人坐上下两侧，直接开始对弈，不需要手机入座或准备。白方在下，黑方在上，黑棋轮廓旋转 180°。轮到哪一方就操作哪一方。
- **手机联机**：先填昵称，点「联机对弈」，用「邀请朋友」提供另一方链接。双方入座、准备后由房主开始。每人自己的阵地在下，棋子保持正向。
- 点自己的棋，再点绿色落点；白方先行。兵到底线时弹出后、车、象、马四种选择，选定后才提交行棋。点王再点横移两格的目标即可易位，车自动移动。
- 可悔棋、提议和棋、认输或查看分页棋谱。同屏和棋须确认，认输须明确白方或黑方。悔棋会恢复易位权、过路兵权和升变前的棋子。结束后房主可再开一局，公开结果进入本浏览器战绩。详见 [棋类悔棋](board-undo.md)。

## 规则与边界

`shared/chess.ts` 提供类型、坐标和合法落点，`server/games/chess.ts` 使用 [chess.js 1.4.0](https://jhlywa.github.io/chess.js/) 验证每一步。服务器持有完整历史，不信任客户端落点或升变值，也不接收客户端 FEN。包括王安全、被牵制的棋子、将军与解围、长短易位权、吃过路兵的即时窗口，以及四种升变。

将死判对方获胜；未被将军但无合法走法为逼和；引擎认定子力不足时和棋。本房间采用固定休闲约定：同一局面（含行棋方、易位权和有效过路兵权）三次出现，或连续 50 回合（100 手）没有吃子且没有移动兵，直接自动和棋。没有另行申请程序或比赛棋钟。

手机操作按凭证绑定的座位执行，不能通过 `side` 字段替对方操作；同屏由当前有效平板房主控制双方，拒绝远程入座、过期房主及其他游戏命令。断线暂停，重连恢复；请求去重沿用共用房间机制。不提供牌类游戏的托管；人机对弈使用服务端本地 CPU 引擎，无私有手牌或云端模型请求。对局保存在内存中，重启服务后清空。

准备页可设置棋钟。超时方的对手若仅剩王、王加一象或王加一马，本房间判和。详见 [棋类棋钟](board-clock.md)。

## 人机对弈

首页进入「棋类」后可选择国际象棋的「人机对弈」，或在准备页设置电脑。五档分别为入门、简单、普通、困难、挑战，均使用 Stockfish 原生引擎与官方 NNUE。平板可选择先后手，手机默认玩家执白；电脑思考期间禁止替它走棋。超时或无效结果会暂停并提供重试。详见 [棋类 AI](board-ai.md)。

## 行棋反馈

正式行棋共约 900 ms，由共享 `useBoardPlayback` 保留移动前棋盘，棋子到达后再淡出被吃子。虚线起点、实线终点、方向箭头和行棋方颜色的路线持续到下一步；浅色描边使标记在深浅方格上均可辨认。“上一手”显示手数、坐标、吃子、将军、易位和升变信息。

易位同时移动王和车，并保留两条路线；吃过路兵淡出 `capturePoint` 位置的兵，不误删落点；升变先以兵完成移动，再显示服务器确认的升变棋子。手机、相向平板和人机模式使用同一套各自视角坐标。动画期间不接受重复走子，结算等待最后一步播完；重连不补播历史，减少动态效果时仍保留静态路线。

## 教程

右上角提供 39 段纯动画教程：棋盘和轮流、六种棋、吃子、兵的移动、10 个禁行示例、两侧易位、吃过路兵、四种升变、三种应将方式及胜负和棋。支持暂停、继续、重播、上一段、下一段和分页目录；教程进度独立保存，不改变正式房间或战绩。

教程通过真实引擎重放服务端剧本。固定局面仅用于服务端素材与测试；50 回合片段明确从计数 99 的教学局面开始。`ChessBoard` 和 `ChessToken` 由正式对局和教程共用，易位同时移动两子、吃过路兵移走相邻兵、落地升变。

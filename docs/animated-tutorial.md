# 纯动画机制教程

右上角教程入口覆盖手机牌桌、私人手牌屏和平板。教程按机制分段，自动播放至结果后停留，点击下一段继续；支持暂停／继续、重播、上一段、目录和退出。纸牌只用横屏，竖屏时暂停并提示旋转；军棋支持局部放大与全局视角；中国象棋使用竖屏并可放大棋盘局部；国际象棋使用竖屏全盘演示。

## 内容与规则来源

`server/tutorials/` 原有完整合法剧本继续作为素材与规则回归用例。`clips.ts` 从剧本中提取固定检查点、实际动作及真实结果；依据机制标签去重，保留全部不同机制和特殊结果。目前斗地主 25 段、掼蛋 31 段、军棋 29 段、象棋 40 段、国际象棋 39 段。象棋覆盖七种棋、各类挡子和禁行、将军的三种解围方式、将死、困毙、认输及本房间支持的和棋约定。固定局面只在服务端构造；120 手无吃子由前面连续 117 手合法操作到达演示起点。

结算片段从触发结果的实际动作之前开始；进贡、还贡片段包含当前阶段的全部提交与公开；抗贡由新一副真实发牌触发。没有从客户端指定牌组或拼接输赢结果的入口。失败示例同样调用引擎校验，确认拒绝后快照完全不变。`copy.ts` 提供面向观看者的通俗说明，不展示作者阶段的练习指令。

## 播放与绘制

围棋另提供 13 段基础与 9 段进阶，五子棋提供 10 段。`server/tutorials/stones.ts` 直接运行正式 `StoneGame` 规则引擎生成固定局面短片，拒绝示例验证快照未变。围棋入口先选择基础或进阶，服务端按分区过滤目录，客户端按分区独立保存观看进度；进阶不会自动接在基础后。进阶片段的可选外站课程来源与规则约定见 [围棋说明](go.md)。所有外链由原站提供内容，本站不复制视频。

`src/tutorials/motion.ts` 是单一逻辑时间轴：同一时间决定当前快照、动作进度、字幕与镜头。暂停停止时钟；重播从不可变片段起点开始；旋转、缩放或进入后台时暂停，恢复后由用户继续。没有独立运行的 CSS 动画、固定屏幕坐标移动副本或未清理的 DOM 动画节点。

`TutorialAnimationStage` 复用原有扑克牌图案和军棋棋盘。军棋使用共享坐标、真实道路/铁路路径和 SVG 曲线采样，局部镜头必须包含完整路线。交战、亮旗、全军清除与结果变化由快照驱动。静止与移动棋子均使用 `JunqiToken`；字体、字号、内框、颜色、圆角和阴影一致，镜头统一缩放整个 SVG。正式军棋继续使用同一个棋子组件。

象棋复用 `XiangqiBoard` 和 `XiangqiToken`；马沿马腿再斜走，相经过象眼，车炮沿横竖线经过完整路径，炮吃子时越过炮架。吃子到达后再移除对方棋，拒绝动作退回起点并显示禁止标记。镜头、棋子、字幕和结果都由同一时钟驱动。手机联机及其教程的所有棋字统一朝下；只有平板同屏及其教程把黑方棋字旋转 180°。朝向由房间模式决定，不根据屏幕尺寸猜测。象棋教程目录分页，不依赖滚动。

国际象棋的 `server/tutorials/chess.ts` 使用服务端固定 FEN 和实际引擎命令生成片段，覆盖六种棋、兵的初次两格与斜吃、两侧易位、吃过路兵、后车象马四种升变、将军三种解围方式及胜负和棋；10 个错误示例确认引擎拒绝且快照不变。50 回合片段明确从半回合计数 99 的固定教学局面开始，不表示重放了此前 99 手。

`ChessTutorialStage` 与正式对局共用 `ChessBoard`、`ChessToken`。王车易位同时移动王和车；吃过路兵从相邻格移除被吃兵；升变在落地时变更棋子轮廓。所有动画由同一逻辑时钟驱动，正式局面与教程进度相互隔离。同屏教程把黑棋旋转 180°，手机教程保持统一朝向。

## 连接与进度

`shared/tutorialProtocol.ts` 课程版本为 `animation-clips-v2`，`/ws/tutorial` 只接收开始／恢复、选段和退出。响应包含目录、片段起点、动画帧、说明与焦点，不再提供练习阶段或玩家游戏操作。请求 ID 和节点版本拒绝重复及过期提交；快速选段合并为最后一次选择，旧响应不能覆盖新片段。

独立 `tabletop:tutorial:<game>` 保存课程版本、当前片段和已观看片段。旧练习进度从新版首段开始；刷新或断线通过确定性重放恢复该段。重连后暂停等待用户播放，不会漏播。教程不加入房间列表、不持有正式 token、不进入模型或战绩采集路径；原房间仍持续运行。

## 验证

`tests/teachingSession.test.ts`、`tests/xiangqiTutorial.test.ts` 和 `tests/chessTutorial.test.ts` 检查完整素材剧本合法性、牌数守恒、真实终局、机制覆盖、全部观看片段、失败局面不变、结果实际发生、确定性恢复、过期/重复请求、旧实践接口拒绝、独立 WebSocket，以及四国弯道正反向几何与镜头边界。

运行 `npm test` 和 `npm run build`。浏览器检查每个片段自动播放并停留、无游戏控件、正式指令与存储隔离、横屏约束、暂停续播、重播、选段、恢复、退出清理；用正常时钟抽查棋子外观与动态线路，并检查私人手牌屏和平板。桌面浏览器的移动视口验证不等于真实手机触控验收。

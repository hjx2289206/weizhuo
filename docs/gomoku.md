# 五子棋

首页进入“棋类”后选择五子棋。提供 SVG 棋盘、平板双人同屏、两部手机联机、教程、断线恢复、棋谱和战绩。当前为真人对弈，未接入五子棋 AI。

## 操作和规则

1. 平板直接开始；手机先填写昵称并开房，邀请白方入座，双方准备后房主开始。
2. 竖放设备，15×15 交叉点，黑先白后。先点空点预选，再点“确认落子”；未确认时可换点或取消。
3. 横、竖、两条斜线均有效，同色连续五子或更多立即获胜，并标出连线。隔空、夹着敌子不算。
4. 本房间采用**普通无禁手**规则，不是连珠竞赛规则：三三、四四、长连都不禁止，不设交换开局。六连以上同样获胜。
5. 棋子不能移动或提走，不提供悔棋，也不能停一手。满盘仍双方无五连时判和；一方认输则对方获胜。
6. 双人平板认输时先选认输一方；联机只能替自己认输。结束后房主可再开一局，黑方重新先行。

掉线暂停，重连恢复棋盘与执子身份。棋谱和公开战绩保存在本浏览器，服务重启不保留原房间。

确认后播放落子／放大和短暂涟漪；最后一子保留外圈及黑白对比的内点，棋盘上方显示手数、执子方和坐标。动画期间禁止重复提交，获胜的最后一子播完才展示结算。重连不重播旧步，减少动态效果时保留静态落点提示；这套反馈不改变预选、确认和胜负规则。

## 教程

游戏卡片或右上角“教程”可观看 10 段：棋盘与操作、横连、竖连、两种斜连、无禁手与长连、防守冲四、非法落点与抢回合、满盘和棋、认输与重开。

动画使用正式规则引擎计算，失败演示保持盘面不变。可暂停、重播、选段，并展开完整说明。观看进度独立于围棋和其他游戏保存，教程不改变正式对局。

# 五子棋

首页进入“棋类”后选择五子棋。提供 SVG 棋盘、平板双人同屏、两部手机联机、五档人机对弈、教程、断线恢复、棋谱和战绩。

## 操作和规则

1. 平板直接开始；手机先填写昵称并开房，邀请白方入座，双方准备后房主开始。
2. 竖放设备，15×15 交叉点，黑先白后。先点空点预选，再点“确认落子”；未确认时可换点或取消。
3. 房主在准备页可选择**无禁手（默认）**或**黑方禁手**。手机联机改规则后双方需重新准备。开局后规则锁定，再来一局沿用上局规则。两种规则都黑先白后、轮流落子。
4. 横、竖、两条斜线均有效，以同色连续棋子判胜并标出连线。无禁手时，黑白双方五连或长连均获胜。黑方禁手模式下，黑方必须恰好五连，白方五连或长连均获胜。
5. 点“悔棋”可以撤销着法。真人联机需对手同意，双人同屏需确认，每方每局可成功悔棋 3 次。满盘仍双方无五连时判和，一方认输则对方获胜。五子棋每回合须落子。详见 [棋类悔棋](board-undo.md)。
6. 双人平板认输时先选认输一方；联机只能替自己认输。结束后房主可再开一局，黑方重新先行。

掉线暂停，重连恢复棋盘与执子身份。本局棋谱和浏览器公开战绩显示规则。服务重启不保留原房间。

## 黑方禁手

黑方落子同时形成两组活三、两组四，或连续六子及以上时，服务端会拒绝并显示「禁手：三三」「禁手：四四」或「禁手：长连」。这是休闲规则，落错点后仍轮到黑方，可以改走其他空点。恰好五连优先于同一手形成的其他禁手形状。

活三须能在合法点延伸成两端都能恰好成五的直四。系统递归检查延伸点，排除延伸本身是禁手的假三。直四的两个胜点仍只算同一组四；同一条线上的两组不同四可以组成四四。棋形判定参考 [国际连珠规则第 3、9 节](https://www.renju.net/rifrules/)。

黑方回合默认显示小叉，可以关闭「禁手提示」。白方回合隐藏小叉。旁观者也能看到当前规则和黑方的公开禁手点。

确认后播放落子／放大和短暂涟漪；最后一子保留外圈及黑白对比的内点，棋盘上方显示手数、执子方和坐标。动画期间禁止重复提交，获胜的最后一子播完才展示结算。重连不重播旧步，减少动态效果时保留静态落点提示；这套反馈不改变预选、确认和胜负规则。

## 人机对弈

点大厅五子棋卡片的「人机对弈」或在准备页选择难度。手机默认你执黑（先手），平板可选「执黑（先手）」或「执白」。电脑执黑时先落天元。电脑思考时落子和悔棋按钮不可用，异常可点「重试电脑行棋」。

等电脑走完后点「悔棋」，退回到你上一手之前，次数不限。重新落子后电脑从新局面应手。五档是自研搜索的相对难度，服务端在后台线程搜索，使用正式五子棋规则引擎提交落子。详见 [棋类 AI](board-ai.md)。

## 教程

游戏卡片或右上角“教程”可观看 13 段。基础内容包括落子、四个方向的五连、防守、和棋和重开，黑方禁手章节分别演示三三、同线四四和长连。

动画使用正式规则引擎计算，失败演示保持盘面不变。可暂停、重播、选段，并展开完整说明。观看进度独立于围棋和其他游戏保存，教程不改变正式对局。

# 军棋接入与验收（2026-10-29）

## 实现范围

- 共用首页军棋入口，在准备页选择双人暗棋或四国四暗。只支持真人联机，每人使用私人屏幕，拒绝公共平板房间。
- 已移除军棋人机练习、机器人补位、托管及服务端行棋策略。服务端拒绝军棋房间的 `addBot`、`removeBot` 和 `autoPlay` 命令，旧客户端也无法启用；斗地主、掼蛋的机器人与托管保留。
- 四国红绿同队、蓝紫同队，只看自己的 25 枚棋子，队友身份同样隐藏。全员确认布阵后红方先行，依次红、蓝、绿、紫，出局者跳过。
- 129 点 SVG 十字棋盘，四套阵地、中央铁路、外围弯道、行营、大本营。普通棋可沿印制弯道通过，不能在铁路路口换向，工兵可转向。自己的阵地在下方，文字正向。
- 固定竖屏，棋盘与操作区上下排列，支持全盘、放大滚动和我的阵地视图。布阵默认聚焦自己的阵地，确认后显示全盘。军棋页面使用独立的视口内纵向滚动，保留棋盘尺寸及系统安全区，屏幕下方的准备、开始布阵、邀请与规则可通过滑动访问；大厅仍保持固定一屏。
- 保留合法随机布阵与交换、手动行棋、合法落点提示、司令阵亡亮旗、夺旗／无棋可走／认输、70 步无交战和棋、再来一局。四国单军出局清除其余棋子，搭档继续，敌队全军出局后按队结算。
- 保留真人邀请、模式切换、重连。模式切换仅限准备阶段由房主操作，保留原座位身份；缩为双人前需腾空第三、第四座。
- 服务端分别投影暗子，随机不透明 ID，公开棋谱不含隐藏军衔。未出局者断线暂停，已出局者断线不阻塞对局。
- 保存公开战绩、按队伍展示四国胜负，支持公开回顾和 PNG 导出。

- 双人通过两个真实页面入座、准备并点击「开始布阵」，成功进入布阵阶段。布阵页在 320×568、390×844、768×1024 和 844×390 下，滚动后随机布阵、确认布阵、邀请与规则均在视口内，无横向溢出。
- 中国象棋、国际象棋、围棋及五子棋在 320×568 检查了准备、开始和邀请位置，并实际操作准备及打开邀请面板，未发现相同裁切，无需修改。
- `npm run build`：类型检查与生产构建通过。上述浏览器验证不等同于 iOS／Android 真机验证。

## 实局行棋动画（2026-11-06）

- 正式双人／四国页面接入共享 `useBoardPlayback`（后续扩展供其他棋类复用）：只播放同一房间、同一局内新到达的连续一步，保留行棋前的私有投影，约 900 ms 后采用服务器落定棋盘。期间禁止重复走子，结算面板等待最后一步播完。
- `JunqiMove.path` 由服务器在移动前按正式棋规生成，只包含公开棋盘位置；工兵若可走普通棋子的路线，优先使用该路线，避免不必要地暴露工兵身份。路线支持铁路多站、四国弯轨和必要的工兵转弯。
- 两种棋盘共用 `JunqiMoveTrail`：行棋方颜色、虚线起点、实线终点、“起／落”标签和方向箭头保持到下一步；棋盘上方显示上一手的行棋方、坐标及交战结果。交战双方使用移动前可见的棋子，分别按攻击胜、防守胜、同归于尽淡出，不翻开对手暗子。
- 四国播放新一步时切回全盘；断线、跨局／跨房、补收多步、切后台及卸载取消旧动画。重连首个快照只恢复当前局面，系统减少动态效果设置跳过移动但保留路线。
- 浏览器 390×844 双页面实局：红方 A6→A7 后，蓝方页面采样到 30 帧、28 个不同棋子位置，全程身份为 `hidden`；蓝方 E7→E6 时红方页面截图可见暗子在途中。
- 浏览器四页面实局：蓝方 西A1→北E1 沿弯轨移动，红方从“我的阵地”自动回到完整棋盘；同归于尽后起点、终点棋子均移除，路线仍保留。减少动态效果下下一步采样 35 帧未出现移动层，重连后保留第 3 步路线且不补播。
- 验证：`npm test` 354 项通过；军棋规则／路线／播放状态定向测试 32 项通过；`npm run build` 类型检查及生产构建通过。真实 WebSocket 完成双人 132 步、四国 264 步，隐私、重连与完整对局均 PASS。
